# Hi, I'm Fidel

I'm an IB student exploring cybersecurity, computer science, and the way secure
technology can solve real problems. My current work focuses on small defensive
tools that are private by default, explain their decisions, and use synthetic
data instead of exposing real accounts or systems.

## Featured cybersecurity work

### [SecurePass](https://github.com/Fidlef/SecurePass)

A local password-strength analyzer and cryptographically secure password
generator. It uses a bundled zxcvbn estimator, avoids logging or storing entered
passwords, and includes Python and JavaScript tests.

### [PhishGuard](https://github.com/Fidlef/PhishGuard)

A text-only URL-structure analyzer that explains misleading hosts, Punycode,
embedded credentials, and other review signals without opening the link or
claiming a final safety verdict.

### [LogSentinel](https://github.com/Fidlef/LogSentinel)

A local authentication-event dashboard that uses transparent time-window rules,
synthetic data, and careful uncertainty language to prioritize defensive review.

### [CyberVault](https://github.com/Fidlef/CyberVault)

A localhost file-encryption demonstration using scrypt-derived keys and
AES-256-GCM, with a versioned format, tamper detection, tests, and an explicit
threat model.

### [HeaderHarbor](https://github.com/Fidlef/HeaderHarbor)

A local `.eml` forensics explainer that separates authentication evidence,
identity mismatches, route clues, and uncertainty without contacting the sender
or opening links.

### [ManifestMirror](https://github.com/Fidlef/ManifestMirror)

A browser-extension manifest auditor that explains individual permissions and
riskier permission combinations without installing the extension.

### [TripwireLedger](https://github.com/Fidlef/TripwireLedger)

A file-integrity monitor for authorized lab folders, with a hash-chained event
ledger that can reveal later edits to its history.

### [FlowSketch](https://github.com/Fidlef/FlowSketch)

A network-flow metadata analyzer that looks for regular timing and unusual DNS
label patterns while preserving normal explanations and avoiding payload data.

### [CookieClinic](https://github.com/Fidlef/CookieClinic)

An interactive lab for learning cookie flags, scope, `SameSite`, and the exact
`__Host-` and `__Secure-` prefix rules with synthetic values.

## How these projects are built

I use AI-assisted development to move from a security problem to a working
prototype, tests, documentation, and a clear limitations section. The initial
implementations are generated with OpenAI Codex. I am responsible for reviewing
and learning the code before I describe any part as my own technical
contribution. The repositories do not claim coursework, certifications,
independent authorship, real-world incident findings, or user-impact numbers.
